# Math Graph Lab

고등학교 함수 그래프 탐구를 위한 모바일 최적화 웹도구입니다.

## Features

- 함수식 입력과 즉시 그래프 렌더링
- `a`, `b`, `c` 계수 슬라이더
- 선택점 기준 수평선/수직선 보조선
- x절편, y절편, 꼭짓점, 축의 방정식 표시
- 비율 관계, 접선의 방정식, 정적분 근사 도구
- 화면/그래프 녹화 후 WebM 저장

## Render

이 프로젝트는 정적 사이트입니다.

- Service type: Static Site
- Build command: `echo Static site ready`
- Publish directory: `.`

`render.yaml`이 포함되어 있어 Render Blueprint로도 배포할 수 있습니다.
